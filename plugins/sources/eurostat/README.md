# Eurostat (`shenas-source-eurostat`)

Eurostat Urban Audit city-level demographics and economics for Shenas.

## Basis

This plugin is part of Shenas's source-plugin cohort. It ships under the [Shenas inclusion policy for source plugins](https://shenas.org/policy/sources) because Eurostat publishes its statistics under the EU's open-data re-use policy, which permits redistribution with attribution to Eurostat as the source. Terms reference: [Eurostat copyright and re-use policy](https://ec.europa.eu/eurostat/about-us/policies/copyright). Scope: this plugin reads Eurostat statistical indicators via the public Eurostat API on behalf of the user; no data is sent off-device by the plugin.

## Attribution

Source: Eurostat. Data re-used under the EU Commission Decision on the re-use of Commission documents.
