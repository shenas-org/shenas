# WHO (`shenas-source-who`)

WHO Global Health Observatory indicators for Shenas.

## Basis

This plugin is part of Shenas's source-plugin cohort. It ships under the [Shenas inclusion policy for source plugins](https://shenas.org/policy/sources) because the WHO Global Health Observatory publishes its indicators for public re-use with attribution to the WHO. Terms reference: [WHO publishing copyright](https://www.who.int/about/policies/publishing/copyright). Scope: this plugin reads WHO Global Health Observatory indicators via the public GHO API on behalf of the user; no data is sent off-device by the plugin.

## Attribution

Source: World Health Organization, Global Health Observatory. Data re-used in accordance with the WHO's publishing copyright policy.
