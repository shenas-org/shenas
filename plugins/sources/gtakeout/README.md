# Google Takeout (`shenas-source-gtakeout`)

Google Takeout connector for Shenas — parses user-initiated Google Takeout archives on the local filesystem.

## Basis

This plugin is part of Shenas's source-plugin cohort. It ships under the [Shenas inclusion policy for source plugins](https://shenas.org/policy/sources) because Google Takeout is a user-initiated export of the user's own data, downloaded by the user to their device; the plugin only parses files the user already controls. Terms reference: [Google Takeout](https://takeout.google.com/) and [Google Terms of Service](https://policies.google.com/terms). Scope: this plugin reads user-initiated Google Takeout archives the user has already downloaded to their device; no data is sent off-device by the plugin.
