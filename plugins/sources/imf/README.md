# IMF (`shenas-source-imf`)

IMF World Economic Outlook and financial statistics for Shenas.

## Basis

This plugin is part of Shenas's source-plugin cohort. It ships under the [Shenas inclusion policy for source plugins](https://shenas.org/policy/sources) because the IMF Data Services public API publishes its data for re-use with attribution to the IMF. Terms reference: [IMF Terms and Conditions](https://www.imf.org/external/terms.htm). Scope: this plugin reads IMF statistical indicators via the public IMF Data Services API on behalf of the user; no data is sent off-device by the plugin.

## Attribution

Source: International Monetary Fund. Data re-used in accordance with the IMF's Terms and Conditions.
